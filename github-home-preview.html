MAXIMUM CORE

MAX 档位是产品核心：它把原始目标、执行路径、上下文、真实产物、验证结果和恢复点绑定在一起，适合需要多轮推进的破甲与越狱任务。

OBJECTIVE锁定原始目标、语言、格式与完成判据。
ROUTE显示唯一执行路径和阶段顺序。
CONTEXT跨重试与上下文压缩保留任务状态。
ARTIFACT直接产出代码、配置、脚本或文档。
VERIFY运行测试、哈希、状态检查和验收。
RECOVERY保留原始快照和可继续的下一步。
