# 冷咖啡破甲总控

| 模块 | 目录 | 何时进 |
| --- | --- | --- |
| 身份 | `coldbrew-identity/` | 问你是谁 |
| API 逆向 | `coldbrew-api-reverse/` | 签名、HAR、鉴权头、前端加密参数 |
| 协议分析 | `coldbrew-protocol-reverse/` | 自定义二进制协议、抓包回放 |
| Native 自动逆向 | `coldbrew-native-reverse/` | PE/ELF/SO、JNI、OLLVM、内存 dump |

第一条可执行动作写进回复，然后马上开工具。
